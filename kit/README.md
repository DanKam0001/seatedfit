# YouCam kit
Keys are self-serve: sign up at https://yce.makeupar.com/ai-api, keys at https://yce.makeupar.com/api-console/en/api-keys/.
Auth: `Authorization: Bearer <key>`. Flow: File API gives an upload URL and file_id, POST the task, poll by task_id, download the result.
Docs saved here: quick_start.md, ai_clothes.md. Units are real money: cache results and never call the API from a public page without a cap.
